Snake Game (Python pygame)

This canvas shows the initial state of the classic Snake game implemented with pygame in Python.

  • Snake: Green squares (4 blocks) starting at position (100, 50) moving right.
  • Fruit: Red square placed at a random location on the grid.
  • Score: 0 (displayed in white at the top‑left).

The actual game runs in a separate window when the Python script is executed.
